# Support

This is a personal project with one maintainer. This file tells you where to ask for help.

## Questions and bugs

* Ask a question, report a bug, or request a change through an
  [issue form](https://github.com/joshwrightcodes/bk-agent-stack-orchard/issues/new/choose).
  Use the form that fits your report.
* Read [README.md](README.md) and the documents in [docs](docs) before you open an issue.
* The maintainer answers when time permits. The project makes no promise of a response time.

## Security reports

Do not report a vulnerability in a public issue. Follow [SECURITY.md](SECURITY.md).

## Developers who use a fleet

An operator runs the fleet that runs this controller. If you are a developer who uses such a
fleet, ask the fleet operator first. The operator controls the profiles, the images, and the
Mac hosts of the fleet. The project cannot see or change them.
