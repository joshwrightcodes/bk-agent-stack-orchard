# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: treat other people with respect, accept that the maintainer decides what the project
accepts, and keep the discussion about the work.

Report unacceptable behaviour to the maintainer through
[a private security advisory](https://github.com/joshwrightcodes/bk-agent-stack-orchard/security/advisories/new)
or a direct message. Reports stay confidential.
